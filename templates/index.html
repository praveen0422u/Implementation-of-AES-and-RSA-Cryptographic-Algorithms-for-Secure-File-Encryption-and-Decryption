Why Hybrid Cryptography? (AES-256 + RSA-3072)

Understanding how modern cryptographic systems combine symmetric and asymmetric algorithms.

1. The Key Distribution Dilemma

Symmetric ciphers like AES are exceptionally fast and secure, but require sender and receiver to share a secret key in advance. Transmitting secret keys across unencrypted channels exposes them to interception.

2. The Asymmetric Size Barrier

RSA solves key distribution by allowing anyone to encrypt with a public key. However, RSA can only encrypt messages smaller than its modulus (e.g., ~318 bytes for RSA-3072 with OAEP SHA-256), making it impossible to encrypt large files directly.

3. The Hybrid Synthesis (.sfe)

The system generates an ephemeral 32-byte AES key and 12-byte nonce for each file. AES encrypts the entire file in GCM mode. RSA-OAEP wraps only the small 32-byte AES key, achieving the speed of AES with the public-key security of RSA.
